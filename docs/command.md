## How should a command look?

**[exe path] [video path] [speed]**

### Definitions:
**[exe path]** -> full path to clianimator.exe or if you have path to clianimator.exe directory in PATH env, then ypu can just type clianimator.  
**[video path]** -> full path to video file.  
**[speed]** -> how much faster/slower will video play, value of 1.00 means it will play with same speed.
